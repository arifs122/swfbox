# Screenshots

Captured from the running library (`swfbox serve docs/demo/swfs`) and the player
page, with the vendored Ruffle build pointed at `--ruffle .swfbox/ruffle`.

| File | What it shows |
| :--- | :--- |
| `library.png` | The library grid: search, AS2/AS3 filters, stage-shaped cards, broken files |
| `player.png` | The player page: Ruffle rendering a SWF, metadata sidebar, prev/next |

1440×1000 at 1.5× device pixel ratio. The `inspect` example in the README is a
terminal SVG (`../demo/inspect.svg`), not a screenshot, so it stays crisp.

## Regenerating them

```bash
node bin/swfbox.js --fetch-ruffle .            # one-time, explicit download
node bin/swfbox.js serve docs/demo/swfs --port 8130 --ruffle .swfbox/ruffle
```

Then, with the server running:

```js
// npm install --no-save puppeteer  (build-time only)
import puppeteer from 'puppeteer';
const browser = await puppeteer.launch();
const page = await browser.newPage();
await page.setViewport({ width: 1440, height: 1000, deviceScaleFactor: 1.5 });

await page.goto('http://localhost:8130/');
await new Promise((r) => setTimeout(r, 2200));
await page.screenshot({ path: 'docs/screenshots/library.png' });

await page.goto('http://localhost:8130/player?f=Neon%20Bolt.swf');
await new Promise((r) => setTimeout(r, 6000)); // Ruffle boot + first frame
await page.screenshot({ path: 'docs/screenshots/player.png' });

await browser.close();
```

The demo SWFs are synthetic files generated by
[`../demo/scripts/make-demo-swfs.mjs`](../demo/scripts/make-demo-swfs.mjs); they
are deliberately tiny, so Ruffle renders simple shapes rather than a game.
